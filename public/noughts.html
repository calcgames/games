How to run it

  1. Download noughts.py or noughts.zip. Pick one: the .py is the quickest route.
  2. If you downloaded the .zip, unzip it and take the Python file out of it. If you downloaded the .py, skip this step.
  3. Connect your calculator via a USB-C cable.
  4. Select 'USB Flash'.
  5. Eject the USB-C attached to the calculator.
  6. Open the Python module on the calculator.
  7. Press on Tools.
  8. Select File.
  9. Select Open.
  10. Open the game file.
  11. Press the right arrow with line-in-front button on your calculator (next to the up button).
  12. Wait for your game to load.
  13. Enjoy.

If your browser or school blocks .py downloads, use the zip instead. If the calculator says Invalid Data Size, the file was changed on the way over. Download it again and copy the new copy.
