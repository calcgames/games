How to run it

  1. Download runner.py or runner.zip. Pick one: the .py is the quickest route.
  2. If you downloaded the .zip, unzip it and take the Python file out of it. If you downloaded the .py, skip this step.
  3. Connect your calculator via a USB-C cable.
  4. Select 'USB Flash'.
  5. Place the Python file alongside the @MainMemory folder (NOT inside of it, ignore the Capt folder if it's present).
  6. Eject the USB-C attached to the calculator.
  7. Open the Python module on the calculator.
  8. Press on Tools.
  9. Select File.
  10. Select Open.
  11. Open the game file.
  12. Press the right arrow with line-in-front button on your calculator (next to the up button).
  13. Wait for your game to load.
  14. Enjoy.

If your browser or school blocks .py downloads, use the zip instead. If the calculator says Invalid Data Size, the file was changed on the way over. Download it again and copy the new copy.
