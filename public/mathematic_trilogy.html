How to run it

  1. Press the Buy button above and pay on the Payhip checkout page. Use a real email address.
  2. Check your email. Payhip sends you a message with your download link straight away (look in spam or junk if it doesn't show up).
  3. Open the link and download the games. Each comes as a .py or a .zip. Pick one: the .py is the quickest route.
  4. If you downloaded .zip files, unzip them and take the Python files out. If you downloaded the .py files, skip this step.
  5. Connect your calculator via a USB-C cable.
  6. Select 'USB Flash'.
  7. Place the Python files alongside the @MainMemory folder (NOT inside of it, ignore the Capt folder if it's present).
  8. Eject the USB-C attached to the calculator.
  9. Open the Python module on the calculator.
  10. Press on Tools.
  11. Select File.
  12. Select Open.
  13. Open the game file you want to play.
  14. Press the right arrow with line-in-front button on your calculator (next to the up button).
  15. Wait for your game to load.
  16. Enjoy.

If your browser or school blocks .py downloads, use the zips instead. If the calculator says Invalid Data Size, the file was changed on the way over. Download it again and copy the new copy.
