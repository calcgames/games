How to run it

  1. Press the Buy button above and pay on the Payhip checkout page. Use a real email address.
  2. Check your email. Payhip sends you a message with your download link straight away (look in spam or junk if it doesn't show up).
  3. Open the link and download block_puzzle.py or block_puzzle.zip. Pick one: the .py is the quickest route.
  4. If you downloaded the .zip, unzip it and take the Python file out of it. If you downloaded the .py, skip this step.
  5. Connect your calculator via a USB-C cable.
  6. Select 'USB Flash'.
  7. Place the Python file alongside the @MainMemory folder (NOT inside of it, ignore the Capt folder if it's present).
  8. Eject the USB-C attached to the calculator.
  9. Open the Python module on the calculator.
  10. Press on Tools.
  11. Select File.
  12. Select Open.
  13. Open the game file.
  14. Press the right arrow with line-in-front button on your calculator (next to the up button).
  15. Wait for your game to load.
  16. Enjoy.

If your browser or school blocks .py downloads, use the zip instead. If the calculator says Invalid Data Size, the file was changed on the way over. Download it again and copy the new copy.
