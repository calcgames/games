How to run it

  1. Press Download and save tetris.py.
  2. Plug the calculator into your computer with its USB cable and pick the connection mode that shows it as a drive.
  3. Copy tetris.py into the calculator's main memory (the @MainMem folder).
  4. On the calculator, open the Python app, choose tetris.py and run it.
  5. Stop the game any time with SETTINGS or BACK.

If your browser or school blocks .py downloads, use the zip version and unzip it first. If the calculator says Invalid Data Size, the file was changed on the way over. Download it again and copy the new copy.
