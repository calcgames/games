How to run it

  1. Download the geo.py file or the geo.zip file.
  2. (Optional) Unzip the geo.zip and take the Python file out of it.
  3. Connect your calculator via a USB-C cable.
  4. Place the Python file alongside the @MainMemory folder (NOT inside of it, ignore the Capt folder if it's present).
  5. Eject the USB-C attached to the calculator.
  6. Open the Python module on the calculator.
  7. Press on Tools.
  8. Select File.
  9. Select Open.
  10. Open the game file.
  11. Press the right arrow with line-in-front button on your calculator (next to the up button).
  12. Wait for your game to load.
  13. Enjoy.

If your browser or school blocks .py downloads, use the zip version and unzip it first. If the calculator says Invalid Data Size, the file was changed on the way over. Download it again and copy the new copy.
